## Description

When a Kanban column contains enough cards to require vertical scrolling, dragging a card and dropping it anywhere in that column always places it at the top of the column instead of at the intended drop position. Same-column reorders and cross-column drops are both affected when the target column is scrollable. The fix must correctly resolve the drop target card relative to the scroll offset.

## Acceptance Criteria

- [ ] Dropping a card onto a specific card in a scrollable column places it immediately after that target card.
- [ ] Dropping a card below all cards in a scrollable column places it at the bottom.
- [ ] Dropping a card at the top of a scrollable column places it first.
- [ ] Reordering within a non-scrollable column is unaffected.
- [ ] Cross-column drops into a scrollable column land at the correct position.

## Notes

Root cause is likely that the drop Y coordinate is not adjusted for the column's scroll offset, causing hit-testing to always resolve to the first card.
