## Description

When the sliders controlling window conten are in their starting position, cards follow the cursor nicely, but when the window is scrolled, a card, once picked up using the drag'n'drop functionality, is shifted with respect to the cursor. It can still be dragged, reordered etc., but it requires the user to look at the card's position instead of the mouse cursor.
