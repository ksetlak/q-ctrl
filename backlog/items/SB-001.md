## Description

Create the initial Rust project in `backlog/app/` using Cargo. Add Slint as a dependency and verify a minimal window renders on macOS and Linux. This is the foundation every other ticket builds on — nothing else starts until this compiles and runs.

## Acceptance Criteria

- [ ] `backlog/app/` contains a valid Cargo project (`Cargo.toml`, `src/main.rs`).
- [ ] `cargo build --release` in `backlog/app/` produces a binary named `backlog` in `backlog/app/target/release/`.
- [ ] Running the binary opens a native window with a placeholder title ("Scaffold Backlog") on macOS.
- [ ] The same binary compiles on Linux (verify via CI or a Linux machine).
- [ ] `Cargo.lock` is committed.
- [ ] `backlog/app/target/` is added to `.gitignore`.

## Notes

Slint version: use the latest stable. Slint backend: native (not software renderer). No UI beyond a window and a title bar at this stage.
