## Description

Arrange ticket cards into horizontal status columns matching the seven board statuses: OPEN, READY, ON-HOLD, IN_PROGRESS, AWAITING_OPERATOR, CANCELED, DONE. Each column is independently scrollable. This is the core Kanban layout.

## Acceptance Criteria

- [ ] Seven columns rendered horizontally, one per status, in the order defined in `backlog/README.md`.
- [ ] Each card appears in the column matching its `status` frontmatter field.
- [ ] Columns with no cards are still visible (empty state).
- [ ] Each column displays its status label as a header.
- [ ] Columns are independently scrollable when card count exceeds the visible area.
- [ ] Unknown or missing `status` values render the card in a visible "Unknown" column rather than silently dropping it.

## Notes

Column order is fixed for M1. Configurability is a future milestone item.
