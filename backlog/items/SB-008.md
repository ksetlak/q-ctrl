## Description

Replace the separate DONE and CANCELED columns with a single "Closed" column that displays both statuses at rest. When a drag is in progress, the column splits visually into two labeled drop zones: the upper half marks the card DONE, the lower half marks it CANCELED. This reduces horizontal board width while keeping the two terminal statuses clearly distinct and reachable via drag-and-drop.

## Acceptance Criteria

- [ ] At rest the combined column renders all DONE and CANCELED tickets together, each card carrying its status label so the two groups remain distinguishable.
- [ ] When any drag is in progress (card lifted from any column), the combined column splits into two visually distinct halves: "DONE" on top, "CANCELED" on bottom, each with its own label.
- [ ] Dropping onto the upper half writes `status: DONE` to the ticket's frontmatter; dropping onto the lower half writes `status: CANCELED`.
- [ ] The split animation is smooth: halves expand from the column centre as the drag begins and collapse back when the drag ends or is cancelled.
- [ ] Dropping a card that is already DONE into the DONE zone, or already CANCELED into the CANCELED zone, is treated as a same-status drop: no file write, card stays in place.
- [ ] Cancelling the drag (e.g. pressing Escape or releasing outside any column) leaves all tickets unchanged.
- [ ] The board layout adjusts to the reduced column count: horizontal scroll range shrinks accordingly.
- [ ] `main.rs` and `app.slint` are updated to remove separate DONE/CANCELED column properties and replace them with a single combined model or pair fed to the new component.

## Notes

The split zones do not need to be equal halves of the physical column height — they should be equal in visual weight. A horizontal divider line with the two labels ("DONE ↑ / CANCELED ↓") appearing on drag start is sufficient for M2. Animation refinement can follow in a later milestone. The "Closed" label at rest can be omitted in favour of showing "DONE · CANCELED" as a subtitle under the column header.
